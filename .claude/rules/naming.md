# Naming Conventions

All source code and application-related names must be in **English**:

- Class names, record names, interface names
- Property and field names
- Method and variable names
- File names
- API route paths and query parameter names
- JSON property names (request/response DTOs)
- Database column names (when applicable)

**German is allowed** only in:
- User-facing display strings (UI labels, error messages shown to end users)
- Code comments explaining domain concepts
- Documentation files (`docs/`)
